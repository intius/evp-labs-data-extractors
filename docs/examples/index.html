Public runnable examples

50 ready-made Apify task presets for high-intent public data workflows. Each example opens on Apify with saved input, public documentation, and export options for JSON, CSV, Excel, API, MCP, and automation tools.

How to use these examples

  1. Open a preset and review the saved input before running it.
  2. Run once with the small preset limit, inspect the dataset, then schedule or automate only if the output is useful.
  3. Use the linked Actor documentation for input references, sample rows, MCP setup, Python, Node.js, and n8n kits.
  4. Remember that underlying Actors are pay per result. Presets are intentionally small enough for evaluation.
