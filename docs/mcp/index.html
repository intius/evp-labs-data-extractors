EVP Public Data MCP server

Connect AI agents to curated public data extraction tools for software marketplaces, government opportunities, clinical trials, SEC filings, podcasts, and games. Use the hosted Apify endpoint for the simplest setup, or install the verified local MCP server from the Official MCP Registry release.

Fastest option: hosted MCP endpoint

This curated endpoint exposes the ten published Actor tools plus Apify run and dataset helper tools. It uses streamable HTTP and requires an Apify API token or Apify OAuth in the client.

https://mcp.apify.com/?tools=evpp/wordpress-plugin-directory,evpp/zapier-app-directory,evpp/atlassian-marketplace,evpp/vscode-marketplace,evpp/apple-podcasts-charts,evpp/steam-game-intel,evpp/grants-gov,evpp/usaspending,evpp/clinicaltrials-gov,evpp/sec-edgar-filings,evpp/yc-companies,evpp/ats-jobs-aggregator,evpp/prediction-markets-intel,evpp/shopify-app-store-leads,evpp/substack-publications-leads,evpp/companies-house-uk,evpp/product-hunt-launches-leads,evpp/olx-pl,evpp/remoteok-jobs,evpp/uk-public-tenders

Use an authorization header in clients that do not support Apify OAuth:

Authorization: Bearer YOUR_APIFY_TOKEN

Start with small result requests because the underlying Actors are pay per result.

Verified local server

The local EVP Public Data MCP server is published in the Official MCP Registry as io.github.intius/evp-public-data-mcp. It exposes 11 focused tools, starts without a token for tool discovery, and caps each extraction response at 25 records.

Install the MCPB release Verify in the Official MCP Registry

SHA-256 for the MCPB artifact:

71f918a26a18c9c4bcfead69a2db7ace20bfcba443e19692c808bbdfe89a0dde

Manual local install:

npx -y github:intius/evp-public-data-mcp#v0.1.1

Cost and safety model

  • Extraction calls are charged to the caller's Apify account by the underlying pay-per-result Actors.
  • Use small maximum item limits while testing prompts and client behavior.
  • Every Actor output schema preserves source identifiers or source URLs where available so answers can be verified.
  • The local MCP server performs no background scraping and only calls Apify when a tool is invoked.
