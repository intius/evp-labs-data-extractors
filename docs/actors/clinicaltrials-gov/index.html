ClinicalTrials.gov Scraper - Clinical Study Data API

Scrape and export ClinicalTrials.gov study data as a clean JSON API: sponsors, phases, enrollment, conditions, interventions, locations, outcomes, and status.

Run on Apify Open developer kit

Who uses this

Pharma/biotech competitive intel teams, CROs, investors tracking pipelines, patient-recruitment agencies.

Quick input

{
  "condition": "lung cancer",
  "status": "RECRUITING",
  "country": "United States",
  "maxItems": 10
}
