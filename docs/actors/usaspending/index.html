USAspending Scraper - Federal Contracts & Awards

Scrape and export USAspending federal awards as a clean JSON API: recipients, agencies, amounts, contract types, NAICS, CFDA, dates, and locations.

Run on Apify Open developer kit

Who uses this

GovCon BD teams, federal contractors tracking competitors' awards, journalists, investors in gov-exposed companies.

Quick input

{
  "awardTypes": "contracts",
  "agency": "Department of Defense",
  "minAmount": 1000000,
  "sortBy": "amount",
  "includeDetails": true,
  "maxItems": 10
}
