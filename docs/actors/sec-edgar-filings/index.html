SEC EDGAR Filings Scraper - Full-Text Search & Company Filings

Scrape and export SEC EDGAR filings as a clean JSON API: full-text search results, company filing feeds, form types, accession numbers, dates, and document URLs.

Run on Apify Open developer kit

Who uses this

Investors/analysts, compliance teams, lawyers monitoring disclosures, journalists, AI-agent builders.

  "forms": "10-K,10-Q,8-K",

  "maxItems": 10
