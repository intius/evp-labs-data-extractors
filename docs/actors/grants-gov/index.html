Grants.gov Scraper - Federal Grant Opportunities

Scrape and export Grants.gov federal funding opportunities as a clean JSON API: deadlines, award amounts, eligibility, agencies, CFDA numbers, and synopses.

Run on Apify Open developer kit

Who uses this

Grant writers/consultants, nonprofits, universities, SBIR applicants monitoring federal funding.

Quick input

{
  "keyword": "infrastructure",
  "oppStatuses": [
    "posted"
  ],
  "includeDetails": true,
  "maxItems": 10
}
