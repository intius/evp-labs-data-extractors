Grants.gov Scraper - Federal Grant Opportunities

Scrape and export Grants.gov federal funding opportunities as a clean JSON API: deadlines, award amounts, eligibility, agencies, CFDA numbers, and synopses.

Run on Apify Open developer kit

Who uses this

Grant writers/consultants, nonprofits, universities, SBIR applicants monitoring federal funding.

Quick input

{
  "keyword": "infrastructure",
  "oppStatuses": [
    "posted"
  ],
  "includeDetails": true,
  "maxItems": 10
}

Integration options

  • Python API quick start
  • JavaScript API quick start
  • MCP instructions for AI agents
  • OpenAPI schema
  • Direct hosted MCP tool URL

Ready-made examples

  • Nonprofit Grant Deadline Monitor
  • Science and Technology Grant Radar
  • Health Research Grant Opportunities
  • Small Business Grant Funding Scan
  • Infrastructure Grant Opportunity Alerts
