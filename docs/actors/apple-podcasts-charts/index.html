Apple Podcasts Scraper - Charts, Search & RSS Feeds

Scrape and export Apple Podcasts charts and search as a clean JSON API: rankings, show metadata, artists, genres, RSS feed URLs, and episode counts.

Run on Apify Open developer kit

Who uses this

Podcast booking agencies, PR firms, ad networks, podcast hosting competitors.

Quick input

{
  "country": "us",
  "chart": "top",
  "genreId": "1488",
  "includeFeedUrl": true,
  "maxItems": 10
}
