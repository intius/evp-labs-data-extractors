Privacy policy

How EVP Labs data extractor documentation, MCP software, and public Actor integrations handle information. Last updated: 2026-11-25.

Summary

EVP Labs does not operate a tracking or analytics service for these tools. The local MCP server runs on the user's machine and calls Apify only when the user invokes a tool. The hosted MCP endpoint and Apify Actors are operated by Apify and process the user's token, inputs, runs, and datasets according to the user's Apify account and Apify's privacy policy.

Information processed

  • Apify credentials: the user's Apify token or OAuth session is supplied by the user's MCP client and is used only to authenticate requests to Apify. It is not included in the MCP package or source repository.
  • Tool inputs: search terms, filters, and item limits are sent to Apify so the selected public data extractor can run.
  • Tool outputs: extractor results are public-source records returned through Apify datasets. Run and dataset retention is controlled by the user's Apify account settings.
  • Documentation access: this documentation site is static and is hosted on GitHub Pages. GitHub may process standard hosting logs under its own privacy terms.

What EVP Labs does not do

  • No advertising trackers or analytics beacons are intentionally included in the documentation site or MCP server.
  • No user credentials are sold, shared with unrelated third parties, or committed to source control.
  • The local MCP server does not run background scraping jobs and does not retain extraction results outside the user's MCP client and Apify account.

Third-party processing

Apify processes Actor runs, authentication, datasets, billing, and logs. Review Apify's privacy policy before using the hosted endpoint or running an Actor. GitHub processes repository, release, and GitHub Pages traffic under GitHub's privacy terms.

Security and contact

Use client-side secret storage for Apify tokens, start with small item limits, and rotate tokens if they may have been exposed. Report security or privacy concerns through the repository issue tracker or the security policy in the repository.
